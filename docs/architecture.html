Control Flow

Detect, remediate, verify, learn, then prevent recurrence. Proactive prevention is distinct from post-remediation learning. The architecture registry in server/precedence.js describes precedence; it does not itself grant execution authority.

Open Engineering Work

  • Replace host assumptions with qualified configurable policies.
  • Complete adapter safety review, permission boundaries and recovery testing.
  • Verify the native shell, installer, upgrade, rollback and data retention.
  • Review jointly authored changes independently before release.
