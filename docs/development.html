Development and Validation

Use Node.js 22 or newer. Run npm test for the explicit adapter-free test list and npm run check for module/load validation. These do not establish real Windows control or release readiness.

The package has no npm runtime dependencies. Native desktop development separately requires the .NET SDK and package restore. It is intentionally not part of public CI yet.

Browser Fixtures

Install Playwright outside the repository if desired. Point PLAYWRIGHT_MODULE at its module and inspect the browser test's channel selection. The cockpit fixture accepts PCP_SKIP_BASELINE=1; its historical local baseline is not distributed. Tests write ignored output and use mocked Windows responses.

Release Gates

No production installer is published. Requirements include supported adapter implementation, threat review, per-hardware calibration, signed build provenance, clean-machine installation and uninstall, upgrade/rollback, data retention, sleep/resume, session isolation and independent exact-candidate review.

Scope of Checks

Public CI checks source hygiene and isolated JavaScript behavior. It does not run privileged commands, load hardware drivers, alter display warmth, restart adapters or apply power plans.
