Frontend Verification

This note records the scope of the frontend checks completed on November 20, 2026. It contains no workstation readings, identifiers, screenshots or private runtime records.

Published Improvements

  • Monitoring distinguishes connecting, live, cached, stale, disconnected, paused and superseded states.
  • Interrupted updates retain the last readings without presenting them as current measurements.
  • Retry requests a status refresh; it does not apply a mode or perform a Windows recovery action.
  • Unchanged markup is reused, and overlapping refresh requests are coalesced.

Development Installation Checks

The five served frontend assets matched the applied development source. The live status endpoint responded, the observer reported no error, and actual status and fast telemetry events reached the browser.

An isolated test browser lost its stream and network connection, displayed reconnecting and last-reading states, then recovered after connectivity returned and Retry was selected. Cached readings remained labelled as cached after reconnection. No Windows mutation request was attempted.

Browser checks found no normal-operation JavaScript errors or horizontal page overflow at 1920 by 1080 and 1280 by 720. Complete telemetry collection remained slower than fast stream updates; the state display does not solve collector latency.

Public Preview Boundary

These live checks exercised a separate development installation. They do not establish that this sanitized public snapshot is runnable, that its missing Windows adapters are qualified, or that an installer is production-ready. The public startup block remains intentional.

Repeatable Public Checks

Run npm test and npm run check. Frontend state regression tests are in tests/render-state.test.js; browser fixture requirements and release gates are described in Development and Validation.

Raw local diagnostics remain private. Future reports should distinguish source tests, mocked browser tests, live integration checks and packaged release acceptance.
