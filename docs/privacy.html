Privacy and Publication Boundaries

This repository begins with a new sanitized history. It is not a mirror of a personal workstation or its original Git history.

Excluded

  • Runtime state, telemetry, event logs, crash dumps, audit history and learned sessions.
  • Credentials, environment files, signing material, account configuration and device identifiers.
  • Private coordination records, handoffs, local screenshots and qualification receipts.
  • Generated build folders, installers, vendor binaries and backup archives.
  • Suspended standalone Windows scripts and personal hardware/performance profiles.

Neutralized

Hardware inventory starts unconfigured. External performance evidence starts empty. Failure signatures retain recognition logic but no private documented evidence. Archive defaults are relative to the local data directory, not a specific drive.

Future Contributions

Ignore rules are only one barrier. Review staged content and history before pushing. Use synthetic test records. Do not upload diagnostic bundles without inspecting their contents. Public issue attachments cannot be assumed private.

Configured runtime integrations may contact third-party endpoints for diagnostics or discovery. This snapshot does not launch those integrations during its default checks. A future runnable release must document data flows and obtain appropriate consent.
